# سامانه ارزیابی عملکرد ماهیانه کارکنان

سامانه وب سازمانی برای ارزیابی ماهیانه کارکنان بر مبنای رده پستی، سوالات اختصاصی رده و سلسله‌مراتب سازمانی.

## فناوری
- ASP.NET Core 10 / C#
- SQL Server + Entity Framework Core
- Razor MVC + Bootstrap RTL
- Vazirmatn / فونت وزیر
- JalaliDatePicker برای تقویم هجری شمسی
- ClosedXML برای Excel
- Cookie Authentication + PBKDF2
- Modular Monolith، مناسب تیم کوچک و توسعه تدریجی

## قواعد اصلی کسب‌وکار
1. هر کارمند دارای رده پستی، واحد سازمانی، سرپرست و در صورت نیاز ویژگی «ارزیاب» است.
2. هر رده پستی مجموعه سوالات با سقف امتیاز مشخص دارد.
3. ارزیاب فقط کارکنان مستقیم زیرمجموعه خود را می‌بیند و ارزیابی می‌کند.
4. اگر کارمند زیرمجموعه یک ارزیاب باشد و خود ارزیاب باشد، ارزیاب بالادست می‌تواند ارزیابی او را بازنگری کند.
5. در بازنگری، امتیازهای قبلی حذف نمی‌شوند؛ EvaluationScoreHistory و EvaluatorChangeHistory تغییرات را نگهداری می‌کنند.
6. هر دوره دارای عنوان، تاریخ شروع و پایان شمسی و بازه ارزیابی است.
7. در خارج از بازه ارزیابی، ارزیاب می‌تواند اطلاعات دوره را مشاهده کند اما ثبت یا تغییر امتیاز مجاز نیست.
8. دوره‌های فعال هم‌پوشان پذیرفته نمی‌شوند.
9. ورود گروهی کارکنان از Excel امکان‌پذیر است و کد رده، کد واحد و کد پرسنلی سرپرست برای ساخت سلسله‌مراتب استفاده می‌شود.
10. برای ارزیاب واردشده از Excel، حساب کاربری با کد پرسنلی ساخته می‌شود؛ رمز اولیه باید در اولین استقرار تغییر داده شود.

## ساختار Excel کارکنان
ردیف اول عنوان ستون‌ها:
`کد پرسنلی | کد ملی | نام و نام خانوادگی | کد رده پستی | کد واحد | ارزیاب؟ | کد پرسنلی سرپرست`

## راه‌اندازی
1. .NET 10 SDK و SQL Server نصب باشد.
2. مقدار ConnectionStrings:Default را تنظیم کنید.
3. `dotnet restore`
4. برای محیط تازه `dotnet run`؛ برنامه در اولین اجرا دیتابیس را ایجاد می‌کند.
5. برای دیتابیس سازمانی موجود، اسکریپت `Database/001_initial.sql` را اجرا کنید.
6. ابتدا واحدهای سازمانی و رده‌های پستی/سوالات را تعریف کنید.
7. سپس Excel کارکنان را وارد کنید.
8. یک دوره مثل «شهریور ۱۴۰۵» با بازه ۱۴۰۵/۰۶/۲۱ تا ۱۴۰۵/۰۶/۲۵ تعریف کنید.

## حساب اولیه
نام کاربری: `admin`
رمز اولیه: `ChangeMe123!`
این رمز باید بلافاصله پس از نصب تغییر کند.
